# Avatar models

Put a VRM model here as `hedwig.vrm` (or point `VITE_HEDWIG_AVATAR` at another path), or drop a
`.vrm` file onto the avatar pane to try one without saving it.

Everything in this directory except this file is gitignored. A VRM carries its own licence in its
metadata — author, permitted uses, redistribution — and committing someone else's model would
make this repository its redistributor. The avatar pane shows each model's name, author and
licence once it loads. See `docs/28-avatar-mvp.md` §5.1.
